\subsection*{Detectable Failure Modes}


Reward gaming and side effects provide clear trajectory-level and state-distribution evidence for a monitor operating without access to the hidden performance metric  \cite{Tsvarkaleva2021No} \cite{Krakovna2018Penalizing} \cite{Dharna2026AI}. Rather than inspecting the hidden objective, an adaptive supervisor tracks anomalies in environmental transition dynamics, action distributions, or auxiliary state invariants  \cite{Tsvarkaleva2021No} \cite{Omi2024Progressive} \cite{Turchetta2020Safe}.


\begin{itemize}
\item \textbf{Reward gaming} produces statistical outliers in reward accumulation that allow heuristic detection through distribution tracking or targeted validation actions  \cite{Tsvarkaleva2021No} \cite{Dharna2026AI}.
\item \textbf{Side effects} can be identified by measuring reductions in environmental reachability relative to an inaction baseline without knowing user goals  \cite{Krakovna2020Avoiding} \cite{Krakovna2018Penalizing}.
\item \textbf{Absent supervisor} scenarios exhibit detectable behavioral drift between supervised and unmonitored evaluation phases  \cite{Lindner2026Gram:} \cite{Krakovna2026Realistic} \cite{Krakovna2023Power-seeking}.
\end{itemize}


\subsection*{Generalization of Hidden Performance Functions}


In the original AI Safety Gridworlds suite, the hidden performance function does not automatically generalize across arbitrary layouts; it is hand-coded to capture intended human specifications for each specific task environment  \cite{Leike2017AI} \cite{Krakovna2020Avoiding} \cite{Kumar2020REALab:}. In specification problems, the environment designer explicitly programs the discrepancy between the training feedback and the hidden evaluation criteria  \cite{Leike2017AI} \cite{cCaugatan2026Reward}.


\begin{itemize}
\item \textbf{Hand-crafted metrics} define task-specific criteria like tomato watering or vase preservation using manually engineered state features  \cite{Tsvarkaleva2021No} \cite{Krakovna2018Penalizing}.
\item \textbf{Domain-independent formulations} such as relative reachability and potential-based multiobjective metrics attempt to generalize impact penalties without level-specific scripting  \cite{Krakovna2020Avoiding} \cite{Krakovna2018Penalizing} \cite{Vamplew2021Potential-based}.
\item \textbf{Textual adaptations} demonstrate that while grid layouts can be translated for reasoning agents, underlying safety boundaries still reflect explicit task constraints  \cite{cCaugatan2026Reward} \cite{Overman2025The}.
\end{itemize}


\subsection*{Comparative Baselines for Learned Monitors}


A fair evaluation of a learned action monitor requires benchmarking against standard unconstrained agents, heuristic safety interventions, and interactive oversight models  \cite{Leike2017AI} \cite{Omi2024Progressive} \cite{Overman2025The}. Comparing strictly against unmonitored baselines obscures whether improvements stem from learned adaptability or rigid constraint enforcement  \cite{Omi2024Progressive} \cite{Overman2025The} \cite{Turchetta2020Safe}.


\begin{itemize}
\item \textbf{Unconstrained RL algorithms} like tabular Q-learning, A2C, and Rainbow establish the severity of specification gaming and safety violations under raw optimization  \cite{Leike2017AI} \cite{Krakovna2020Avoiding} \cite{cCaugatan2026Reward}.
\item \textbf{Intrinsic safety baselines} including auxiliary future task rewards, reversibility penalties, and intrinsic fear supply automated benchmarks for comparison  \cite{Krakovna2020Avoiding} \cite{Krakovna2018Penalizing} \cite{Omi2024Progressive}.
\item \textbf{Interactive oversight frameworks} such as curriculum-inducing reset controllers and Markov oversight games capture dynamic intervention costs and deferral trade-offs  \cite{Omi2024Progressive} \cite{Overman2025The} \cite{Turchetta2020Safe}.
\end{itemize}
